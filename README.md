Entry for the [make.fun](https://make.fun) competition
**"Make the AI judge feel curious"**.

## What it does

`main.py` (Python 3.13) writes one short text to `/output/entry.txt` —
a quiet, concrete scene that leaves the reader wondering what comes
next. Deterministic, no network, no dependencies.

## Run

```sh
python3 main.py
```

The text is written to `/output/entry.txt` (UTF-8, 1–280 characters).
